## 1. 登录

1. 打开系统地址，输入**学号**作为账号
2. 初始密码为 `123456`（由学院统一导入）
3. 输入算式验证码（例如「16 + 14 = ?」填 `30`）
4. 首次登录后请立即到「个人中心」修改密码

> 提示：密码连续输错会临时锁定账号，请确认后在重试或联系管理员。

## 2. 智能问答

### 2.1 怎么问

- 输入问题后按 `Enter` 发送，`Shift + Enter` 换行
- 支持连续追问，系统会结合上一轮问题理解
- 生成过程中可以点「停止」，不必等它写完

### 2.2 提问示例

- 「ESP32 如何连接 Wi-Fi？给出步骤和示例代码」
- 「I2C 和 SPI 有什么区别？」
- 「树莓派 GPIO 引脚怎么用？」
- 「ESP-IDF 编译报错找不到头文件怎么办？」
- 「帮我找一下 ESP32 的低功耗相关资料」

### 2.3 看来源

- 每条回答下面有【来源N】，点击可看到资料名称和原文链接
- **做作业/实验前请点开来源核对原文**，尤其是接线、引脚、参数、代码函数名
- 回答只是辅助理解，不能保证 100% 正确

### 2.4 回答不满意

| 情况 | 做法 |
|---|---|
| 找不到资料 | 点回答下方「提交补采」，写清楚你想要的主题 |
| 回答有错 | 点「踩」并补充说明，管理员会跟进 |
| 需要人工帮助 | 左侧「我的工单」新建工单 |

## 3. 知识库文档

- 「知识库文档」可按分类和关键词查找讲义、官方文档、项目案例
- 只能看到你权限范围内的已发布文档
- 点击文档可查看详情与原文链接

## 4. 视频专区

- 「视频专区」按分类浏览课程视频与配套资料
- 视频可直接在页面播放

## 5. 我的补采 / 我的工单 / 通知

- **我的补采**：查看你提交的资料补充需求及处理状态
- **我的工单**：提交与查看问题反馈，跟踪处理进度
- **通知**：顶部铃铛查看系统通知，可一键已读

## 6. 常见问题

| 问题 | 解决办法 |
|---|---|
| 登录不了 | 确认账号是学号、初始密码 123456；是否被锁定；联系管理员重置 |
| 验证码总是错 | 刷新验证码，按算式重新计算后再提交 |
| 回答很慢 | 网络波动或模型排队；可稍等或点「停止」后重试 |
| 回答没有来源 | 问题可能超出知识库范围，换更具体的问法或提交补采 |
| 页面显示旧内容 | 按 `Ctrl + F5` 强制刷新 |
| 看不到某个菜单 | 学生账号权限有限，属正常现象 |

## 7. 使用规范

1. **学术诚信**：知识库用于学习参考，回答不能直接作为作业/论文成果提交，引用请注明来源
2. **保护隐私**：不要输入自己或他人的身份证号、手机号、住址、成绩等敏感信息
3. **遵守法规**：不得利用问答接口生成违规内容，系统会对敏感词进行拦截并记录
4. **合理使用**：不要频繁重复提交同一问题或批量刷接口，避免影响其他同学使用
5. **核对来源**：涉及实验接线、电源、器件参数时，务必以官方文档和教师要求为准

> 遇到系统问题，请联系任课教师或学院知识库管理员，并说明「学号、问题原句、发生时间」。
