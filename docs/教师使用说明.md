## 1. 登录与账号

1. 浏览器打开系统地址，输入账号、密码和算式验证码（按提示算出结果填入）
2. 首次登录后，点击左下角「个人中心」→ 修改密码
3. 连续输错密码会触发临时锁定，请等待或联系管理员解锁

> 账号由管理员创建或批量导入；管理员初始密码由部署人员单独告知，不得转发。

## 2. 智能问答（主要功能）

### 2.1 提问方式

- 在输入框输入问题，按 `Enter` 发送，`Shift + Enter` 换行
- 支持多轮追问（如「它和 SPI 有什么区别？」会结合上一轮理解）
- 生成过程中可点击「停止」中断，避免长回答占用时间

### 2.2 提问建议（提升命中率）

- 带上芯片/框架/模块名：「ESP32-S3 的 GPIO9 能直接用吗？」
- 描述具体现象：「ESP-IDF 编译报 undefined reference to esp_wifi_init 怎么办？」
- 需要操作步骤时明确说「给出步骤/示例代码/参数含义」
- 一次只问一个问题，比「顺便再讲讲……」效果更好

### 2.3 看来源（重要）

- 每条回答下方有【来源N】与文档名、章节/页码、原文链接
- **教学使用前请点击来源核对原文**，尤其是型号、引脚、参数、API 名称
- 回答末尾会标注「仅供教学参考；完整内容请以来源文档为准」

### 2.4 回答不满意时

| 情况 | 操作 |
|---|---|
| 答非所问 / 未命中 | 点击回答下方「提交补采」，填写希望收录的资料主题 |
| 回答有误 | 点「踩」并说明问题，管理员会在补采闭环中处理 |
| 需要人工处理 | 进入「我的工单」新建工单，选择问题类型并描述 |

## 3. 知识库文档

- 「知识库文档」支持按分类、关键词筛选与搜索
- 列表只显示你有权限且已审核发布的文档（密级自动过滤）
- 点击文档可查看详情、章节与原文链接；部分文档支持在线查看内容

## 4. 视频专区

- 按分类浏览课程视频与配套资料
- 视频支持页面内播放；配套资料可在文档区检索

## 5. 我的学生（教师专属）

- 左侧菜单「我的学生」可查看所带班级学生名单
- 名单来自学院统一导入，如需调整请联系管理员
- 名单仅用于教学管理，不展示学生敏感信息

## 6. 通知与个人中心

- 顶部铃铛为消息通知，支持一键已读
- 「个人中心」可修改密码、上传头像、查看个人信息

## 7. 教学使用建议与边界

1. **定位是检索助手，不是教材**：回答基于知识库资料整理，引用来源优先于回答正文
2. **代码与参数务必核对**：尤其 API 签名、寄存器、引脚编号；本地离线模式下 7B 模型可能写出不存在的函数
3. **不要输入敏感信息**：学生身份证号、成绩、联系方式等不要粘贴进提问框
4. **不要依赖它做评分**：回答可能存在遗漏或偏差，不能作为学生评价的唯一依据
5. **知识覆盖范围**：以嵌入式与物联网（ESP32/ESP-IDF、树莓派、电子电路）为主，软件工程与 AI 应用为辅；冷门知识点可能未收录
6. **响应速度**：云端模式通常 5～8 秒；本地离线模式 8～15 秒且不支持多人同时提问

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 验证码看不清/算错 | 刷新验证码重试；连续失败请稍后再试 |
| 登录提示账号锁定 | 等待锁定时间结束或联系管理员 |
| 回答很久不出现 | 检查网络；本地模式模型加载需要时间；可点「停止」重试 |
| 回答没有来源 | 可能命中通用知识补充，请换个更具体的问法或提交补采 |
| 页面还是旧版本 | `Ctrl + F5` 强制刷新 |
| 权限菜单看不到 | 角色权限不同；联系管理员确认角色 |

> 技术支持：请联系学院知识库管理员，并提供「账号、问题原句、发生时间、截图」。
